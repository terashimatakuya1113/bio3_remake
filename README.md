# LAST SHIPMENT ―最終便―

90年代後半の固定カメラ式サバイバルホラーへのオマージュとして作った、オリジナルの短編ゲームです。
1998年10月、封鎖された街の郊外にある製薬会社の物流センターで、救急救命士ナオミが夜明けまで生き延びます。

タイトルからエンディングまで、全5章を遊べます（およそ 20〜30 分）。

1. 管理事務所 … 窓を破る感染犬、起き上がる倉庫係
2. 倉庫棟 … 内側から破られた「特別便」のコンテナと、追跡者ポーターの初登場
3. 冷蔵倉庫 … 立てこもる少女エマ。新薬 LZ-9 を浴びてしまう
4. 無線室・検問所 … 所長ホルトの告白と、後始末に来た「回収課」との対峙
5. 貨物ヤード … ポーターとの最終戦と、記録ディスクをめぐる取引

途中の緊急選択（時間内に選ぶ二択）で展開が変わり、エンディングは 3 種類あります。
やられたときは、その部屋に入ったところからやり直せます。

## 遊び方

ブラウザで動きます。ローカルで遊ぶときは、このフォルダで簡易サーバーを立てて開いてください。

```sh
python3 -m http.server 8000
# → http://localhost:8000/ を開く
```

### 武器

- ナイフ：最初から持っている。弾がいらないので、弾が尽きても戦える。近くの敵を切りつける
- ハンドガン：最初から装備している（装弾数 15）
- ショットガン：倉庫棟のフォークリフト脇で拾える（装弾数 7）。扇形に広がり、近いほど強い
- マグナム：無線室のロッカーの上で拾える（装弾数 6）。威力が高く、並んだ敵を貫通する
- ショットガンの弾は倉庫棟・荷さばき場・冷蔵倉庫・検問所に、マグナムの弾は検問所と貨物ヤードにある
- 武器はステータス画面の「装備」で持ち替え、弾は武器と「組合せ」るか「使う」で装填する
- 弾が尽きて予備もないまま撃とうとすると、自動でナイフに持ち替える

## 当時の質感を出すための工夫

- 原作と同じく、部屋は高精細に事前レンダリングした背景（影・照明・高解像度テクスチャ）を使い、キャラクターと拾えるアイテムだけをリアルタイムに重ねる
- 320×240 で描画し、補間なしで拡大
- 頂点を低解像度グリッドに吸着させて PS1 特有の「ポリゴンの揺れ」を再現
- テクスチャはアフィン補間（パースのかからない歪み）、最近傍補間の 64px テクスチャ
- 頂点単位のライティング（グーローシェーディング）と、15bit カラー＋ディザ
- 固定カメラの切り替え、ラジコン操作、扉を開けるロード演出
- 背景の照明には光のにじみ（ハロー）を足し、影は高解像度のシャドウマップで焼く
- キャラクターは 128px の描き込みテクスチャ（しわ・縫い目・顔の彫り）、指のある手、髪型の違い、頂点カラーに焼いた接触陰影（脇・股・足元）で、後期 PS1 作品の密度に寄せる
- キャラクターの頂点ライティングは上下で強さの違う環境光と半ランバートで、背景の照明になじませる。足元の影は網点でぼかす
- テクスチャと効果音はすべてプログラムで生成（外部素材なし）

## 構成

- `index.html` … 画面とUI
- `src/ps1.js` … PS1風シェーダー、手続き生成テクスチャ、ジオメトリ生成
- `src/rooms/*.js` … 部屋ごとのレイアウト、照明、カメラ、調べられる場所、扉（`kit.js` は共通の道具箱）
- `src/story.js` … 台本：部屋ごとの敵の配置、イベント、緊急選択、エンディングへの分岐
- `src/world.js` … 部屋をまたいで共有する状態と当たり判定
- `src/weapons.js` … 武器の性能表、手に持つモデル、部屋に置く武器と弾
- `src/enemies.js` … 感染者・感染犬・ポーター・回収課の兵士
- `src/npcs.js` … エマ・ホルト・ヴィクトル
- `src/doorscene.js` … 扉を開けるロード演出
- `src/hq.js` / `src/hq2.js` … 背景用の高解像度テクスチャと看板
- `src/bake.js` … 背景の事前レンダリングと実行時の合成
- `src/anim.js` … 歩き・走り・構えなどのアニメーション
- `src/actors.js` … ローポリ人型モデル
- `src/dog.js` … 感染犬のモデルとポーズ
- `src/main.js` … ゲームループ、部屋の読み込み、カメラ、プレイヤー、メッセージ、台本から使う窓口
- `src/fx.js` … 血しぶき・薬莢・血だまりなどの演出
- `src/menu.js` … ステータス画面（心電図・装備・アイテム欄・組合せ）
- `src/itemview.js` … ステータス画面のアイテム 3D 表示と顔の窓
- `src/audio.js` … WebAudio による効果音と環境音楽
- `src/text.js` … ゲーム内の文章

Three.js は CDN（jsDelivr）から読み込みます。
